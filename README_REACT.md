# BudgetBasics (NextGen BudgetBee) - ReactJS Frontend Application

A production-grade, human-designed Financial Literacy & Automated Wealth Planning web application built with **React 18**, **Functional Components**, and **React Hooks (`useState`, `useMemo`, `useRef`, `useEffect`)**.

---

## 🎨 Fintech & Trust Theme Specs
- **Primary Brand Color:** Deep Trust Navy (`#0F172A`)
- **Accent / Growth Color:** Emerald Green (`#10B981`)
- **Background Color:** Clean Off-White (`#F8FAFC`)
- **Card Backgrounds:** Pure White (`#FFFFFF`) with subtle soft shadows (`box-shadow: 0 4px 6px -1px rgba(0, 0, 0, 0.05)`) and 1px border (`#E2E8F0`).
- **Border Radius:** Professional `8px` - `12px`.
- **Typography:** Google Fonts `'Inter'` & `'Poppins'`.

## 🚀 How to Run

### Option 1: Instant Browser Preview (Zero Installation Required)
Simply double click or open **`react_app.html`** in any web browser (Chrome, Edge, Firefox, Brave). It executes the complete React 18 component tree live via CDN and Babel Standalone.

### Option 2: Standard React / Vite Development
1. Open terminal in the project directory:
   ```bash
   cd "d:\APTECH PROJECT"
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start local development server:
   ```bash
   npm run dev
   # OR for Create React App: npm start
   ```
